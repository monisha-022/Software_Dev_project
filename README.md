Smart CSE Lab Management System

Introduction

Smart CSE Lab Management System is a console-based software developed using C++. The main goal of this project is to make laboratory management easier and more organized. It helps manage student records, computer status, lab equipment, attendance, lab booking, and complaints from a single system.

Project Objectives

- Manage student information.
- Keep track of laboratory computers.
- Store attendance records.
- Manage lab equipment.
- Allow students to book lab sessions.
- Record and manage complaints.
- Generate simple reports.

Features

- Admin Login
- Student Management
- Computer Management
- Equipment Management
- Attendance Management
- Lab Booking
- Complaint Management
- Report Generation
- File Handling using text files

Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling (fstream)
- Visual Studio Code
- Git & GitHub
